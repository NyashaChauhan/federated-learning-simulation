# Federated Learning Simulation on MNIST

A simulation of Federated Learning using the Federated Averaging (FedAvg) algorithm on the MNIST handwritten digit dataset.

## Overview

This project demonstrates how multiple clients can collaboratively train a shared machine learning model without sharing their local training data.

The project compares centralized training with federated training under IID and non-IID data distributions.

## Objectives

- Implement a basic federated learning simulation.
- Understand and implement the FedAvg algorithm.
- Compare IID and non-IID data distributions.
- Evaluate federated learning against centralized training.
- Visualize model performance across training rounds.
